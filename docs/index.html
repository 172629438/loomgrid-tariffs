为什么每行都带一个状态

电价数据最容易出的不是错别字，是看着像真的。所以这份数据集给每行标了核实状态： 你能一眼看出这条数据是逐条对过原文、只核了尖峰、还是拿别的省模板套出来的。

要批量算，别在这儿一省一省点

这个页面是给人查的；要跑批量，直接取 CSV。数据以 CSV 为唯一事实源，JSON 由脚本派生，改完 CSV 跑一次重建，两者不会脱节。

example.pypandas
import pandas as pd

s = pd.read_csv("data/province_tariff_summary.csv")

# 只留能用的：模板复制的表不要进测算
usable = s[s.period_table_status == "verified"]

# 按峰谷价差找项目机会
usable.assign(spread=usable.price_peak_cny_per_kwh - usable.price_valley_cny_per_kwh) \
      .sort_values("spread", ascending=False)
